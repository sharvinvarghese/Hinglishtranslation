# 🌐 Hinglish Translation

An ML-powered translator that converts **English to Hindi** using machine learning.

## 🚀 Features
- English → Hindi translation using ML models
- Built and explored in Jupyter Notebook
- Lightweight and easy to experiment with

## 🛠️ Tech Stack
- Python 🐍
- Jupyter Notebook 📓
- NLP / Machine Learning
- HuggingFace Transformers
- PyTorch

## 📦 Installation
```bash
pip install transformers torch pandas numpy matplotlib notebook sentencepiece sacremoses
jupyter notebook
```
